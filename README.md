## 💫 About Me:

Hi there! About me? Testing and building websites is something I enjoy doing. I know manual testing might seem boring, but things start to get exciting when the magic of Selenium knows its part in the plot's home stretch! Postman makes API Testing even more fun.

Computer Vision is another field I am very much intrigued to work on. It is quite amazing to literally teach a computer to **"see"** or recognize objects.
